# План/факт отчёт сети кофеен «Бодрое утро» — Excel

Консолидация помесячных выгрузок продаж из 6 филиалов сети кофеен в единую отчётность: импорт и очистка в Power Query, обогащение справочником через XLOOKUP, план/факт анализ и интерактивный дашборд на сводных таблицах — полностью средствами Excel, без внешних BI-инструментов.

[Скачать таблицу →](coffee_analysis.xlsx)

## О датасете

Данные синтетические, сделаны специально под этот проект (без готового датасета с Kaggle) — чтобы максимально приблизить сценарий к реальной рутине junior DA в рознице: каждый месяц из точек продаж приходят отдельные выгрузки, которые нужно свести воедино.

- Легенда: сеть из 6 кофеен в разных городах РФ (Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск, Краснодар)
- 3 264 транзакции за 2025 год, 6 отдельных файлов-выгрузок (по одному на филиал)
- Каждая выгрузка сделана «грязной» намеренно — как реальный экспорт из разных кассовых систем: разные названия колонок, разное написание филиала, дубли строк, пропуски, даты текстом

## Структура файла

| Лист | Содержание |
|---|---|
| branches | Итоговая объединённая и очищенная таблица транзакций (3 264 строки) |
| spravochnik | Справочник филиалов: город, менеджер, дата открытия, площадь |
| planfact | План продаж по филиалам и месяцам, факт, % выполнения |
| Dashboard | Сводные таблицы, срезы и графики |

## Что сделано

**Сборка и очистка в Power Query**

- Combine Files from Folder — объединение 6 отдельных выгрузок в один запрос вместо ручного копирования
- Приведение разных названий колонок к единому виду (`Date` → `Дата`, `Позиция` → `Товар`, `Продавец` → `Кассир`, `Сумма, руб` → `Сумма`) — переименование сделано на уровне обработки каждого файла по отдельности (функция Transform File), до объединения в общую таблицу
- Преобразование дат с учётом локали (Change Type Using Locale, Russian) — часть дат хранилась текстом в формате ДД.ММ.ГГГГ
- Устранение дублей строк, обработка пропусков (СУММЕСЛИМН-совместимые значения по умолчанию)

**Поиск и сопоставление данных**

- XLOOKUP — подтягивание менеджера и города филиала из отдельного справочника в основную таблицу

**План/факт**

- СУММЕСЛИМН — факт продаж по филиалу и месяцу, сравнение с планом, % выполнения
- Условное форматирование (цветовая шкала) для визуального выделения отстающих точек

**Дашборд**

- 2 сводные таблицы (продажи по городам/категориям, динамика по месяцам) + 3 связанных среза (Город, Месяц, Категория) + 2 графика (столбчатая и линейчатая диаграммы), реагирующие на срезы одновременно

## Качество данных: что было исправлено

В ходе объединения 6 исходных выгрузок (3 310 строк) в единую таблицу (3 264 строки) обработано:

| Проблема | Что сделано |
|---|---|
| Разное написание филиала в одной и той же выгрузке (`Екатеринбург` / `Екб` / `екатеринбург`) | Нормализовано через Capitalize Each Word + точечный Replace Values |
| Разные названия колонок между файлами (`Позиция`/`Товар`, `Продавец`/`Кассир`, `Date`/`Дата`, `Сумма, руб`/`Сумма`) | Приведены к одному виду на этапе обработки каждого файла |
| Даты одного филиала — текстом в формате ДД.ММ.ГГГГ | Распознаны с указанием локали (Russian), без потери и без искажения дня/месяца |
| Дублирующиеся строки транзакций | 46 строк (≈1,4% от исходного объёма) удалены |
| Пропуски в «Кол-во» и «Кассир» | «Кол-во» заменено на 1 по умолчанию, «Кассир» — на «Не указан» |

## Выводы

**Систематически не выполняют план: Екатеринбург и Краснодар.**

По итогам года эти два филиала — единственные, кто не дотянул до плана в целом (Екатеринбург — 87% от плана, Краснодар — 80%), причём отставание не случайное: у обоих 8 из 12 месяцев показали выполнение плана ниже 90%. Остальные четыре филиала (Москва, Санкт-Петербург, Казань, Новосибирск) план либо выполняют, либо перевыполняют.

Гипотеза: план для этих двух филиалов был установлен без учёта их фактического потока клиентов — они не показывают провал в абсолютных цифрах продаж (выручка сопоставима с остальными филиалами, разброс между всеми шестью — не больше 8%), просто изначальный план оказался завышен относительно их реального масштаба. Это стоит проверить с руководством при следующем пересмотре плана, а не считать проблемой самих точек.

**Ярко выраженная сезонность у всех филиалов одновременно.** Продажи проседают в июне–августе (минимум — август, 79 998₽ по всей сети против пиковых 134 533₽ в январе) и снова растут к зиме. Эффект синхронный по всем 6 филиалам — значит, причина не в локальной специфике точек, а в общем сезонном факторе (отпускной период).

**Напитки — основная категория выручки** (686 тыс. ₽ из 1,3 млн ₽ за год, больше половины), Выпечка и Еда делят оставшуюся часть примерно поровну.
